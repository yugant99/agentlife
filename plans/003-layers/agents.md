# Agents — worker characters people recognise

## 1. Audit

Today each agent is one `CourtyardCharacter` inside `Workers.tsx`. `Workers.tsx:92-493` owns spawn/retarget/walk/fade/tether/ring/beam; `CourtyardCharacter.tsx:322-586` owns the body: box torso/skirt/belt, sphere head with dot eyes + cone nose, helm/hood/cap hat (`205-240`), optional beard/cloak/fur, shoulder pads, stick arms/legs with skin hands and boots. Pose comes from `applyGesture` (`142-191`, `STEP_FREQ=7`) driven by `gestureForWorker` in `movement.ts:252-281` (hammer/scroll/telescope/crate/banner/think/talk/idle/sit) plus a walk swing that freezes arms for tool poses (`178-189`). Props are tiny (`HeldProp`, `244-304`: 0.06-wide hammer, r=0.06 scroll, telescope, crate, banner). Scale is `WORKER_SCALE=1.87` (`Workers.tsx:27`), children 0.8× beside parent via `childOffset` (`movement.ts:98-101`). Status at distance is only a ground ring (`ringFor`, `movement.ts:294-304`; mesh `Workers.tsx:460-463`) and a 40-unit amber needs-input beam (`471-484`). Stale sits and greys 55% toward grey (`CourtyardCharacter.tsx:130-135,432-439`); historical walks out idle and fades 8 s (`lifecycle.ts:21-34`, `Workers.tsx:368-373`). Name tags are one drei `Html` per agent (`578-583`), opacity-toggled but always mounted. Identity is `lookFor(id)` (`52-67`): five hardcoded principals plus hash palettes — `provider`, `model`, `role` (`agentModel.ts:10,40-42`) are never read.

Three biggest weaknesses:

1. **No provider identity.** `CityAgent.provider` exists (`codex | opencode | claude-code | manual`) but the body ignores it. A Codex, Claude Code and OpenCode worker at 80 m are the same brown medieval villager with a different hat coin-flip. `model`/`role`/`depth` also have no visual channel. The brief's core question fails.
2. **State is sub-meter.** Thinking is a head tilt (`121-126`), talking a r=0.12 chest glow (`505-509,424-427`), tools are hand props <0.6 units. From city/district zoom (40–150 m) all of it vanishes; only ring color + beam survive. "Thinking / using a tool / waiting for you from 100 m" is unreadable.
3. **A perf cliff at 24→50.** Each figure is ~18 meshes × unique `meshStandardMaterial` with `castShadow` on ~12 (`462-575`), so 24 agents ≈ 400+ draws plus shadow pass on a MacBook Air target (`CourtyardScene.tsx:32,1215-1228`, DPR ≤1.6). Add 24 always-mounted `Html` tags, one `lineSegments` tether capped at 16 (`Workers.tsx:31,390-414`), `MAX_RENDERED_WORKERS=24` (`agentModel.ts:82`) with overflow hidden, and `MAX_LEAVING=6` — at 50 agents draws/DOM/shadows break and the crowd has no staging plan.

## 2. 10x vision

A lantern-golem crew, not villagers: same chunky mythic skeleton for all, but provider is a silhouette + uniform + crest-light readable at 150 m (Codex = forge-helm + amber ember trim, Claude Code = archive hood + jade glow seam, OpenCode = signal cap + sky-blue beacon finial, manual = unlit grey), model seniority is a stripe count, and state is theatre — thinking orbits motes, tool-work swings an oversized light-sigil, waiting-for-you raises the banner and lights the beam — under one contract: city zoom reads color + crest-light, district zoom reads pose + sigil, agent zoom reads face + name + model tick.

## 3. Ranked moves

1. **Provider heraldry kit.** Replace hash hats with provider silhouette + uniform + emissive trim; model → 0–3 shoulder ticks; `manual` stays unlit. Impact 5, effort M, perf ~0 (shared materials, +1 emissive mesh each; degrade: trim off beyond 100 m). Data: `provider`, `model`, `role` (scenery fallback: keep hash coat for unknown). Deps: districts (keep trim hues off window-glow palette), HUD (match roster swatches).
2. **Three-zoom read contract + finials.** Every worker gets a tall crest-light finial (emissive rod/cage, provider color) + enlarged ground sigil; near shows face/props, far shows finial + ring only. Impact 5, effort M, perf +1 draw each, −N from LOD below; degrade: finial hidden under reduced-motion still reads via ring. Data: `workState`/`phase`/`freshness` drive finial pulse; scenery: none. Deps: camera (agree far threshold ~60 m), sky (stays decorative, no hook).
3. **Instanced bodies + 2-level LOD.** Share 6 geometries × ~8 materials across all agents; near (<60 m) full rig, far a merged capsule + finial billboard; shadows only near; kill per-agent material clones. Impact 5, effort L, perf −60–70% draws at 24 agents, enables 50; degrade: all-far mode on slow GPU. Data: scenery (perf only). Deps: none (internal to layer).
4. **Long-range state theatre.** Thinking = 3 orbiting motes; talking = expanding ground ripple; tool = oversized emissive sigil swing (hammer-arc / scroll-sheet / dish-sweep, 2–3 m, not 0.3 m props); needs-input = banner raised + beam (reuse existing beam). Impact 4, effort M, perf 2 instanced additive quads per active agent; degrade: static sigil under reduced-motion. Data: `phase` (thinking/talking/tool), `toolKind`, `workState==='needs-input'`; stale/leaving never play these. Deps: effects layer (share additive palette), districts (sigils stay inside plaza radius).
5. **Apprentice retinue + flowing tethers.** Replace thin `lineSegments` with 1 ribbon per parent (tube, scrolling dash shader), child crest echoes parent hue, depth>1 stacks tighter + smaller. Impact 3, effort M, perf 1 draw per family (cap 8 ribbons); degrade: static line under reduced-motion. Data: `parentId`, `depth`, `freshness` (fresh–fresh only, per `lifecycle.ts:39-44`). Deps: movement (keep `childOffset` spacing).
6. **Crowd director for 24+.** Keep `selectRendered` priority (`movement.ts:212-222`) but stage overflow: second ring + plaza-edge sitters instead of overlap; 24+ renders far-LOD only; roster-listed overflow optionally as rooftop signal wisps (clearly labelled scenery-telemetry hybrid: wisp count = overflow count). Impact 4, effort M, perf flat (wisps are 1 instanced set); degrade: wisps off on weak GPU. Data: render-split counts + `lastSignalAt`; wisps encode count only. Deps: HUD roster (same ordering), districts (sitter spots).
7. **Distance-culled tags.** Mount `Html` only for hovered/selected/needs-input within 40 m (max ~6); everyone else gets a batched canvas-sprite initial or nothing beyond 60 m. Impact 4, effort S, perf −18 DOM nodes, −layout thrash; degrade: tags off entirely under reduced-motion except selected. Data: `name` + `cityStatusLabel` (existing), `workState`. Deps: HUD (inspector stays source of truth), camera (distance source).
8. **Grounded gait.** Add foot-lift curve, body bank into turns, jog blend by `tripSpeed` (`movement.ts:21-24`), plant feet when working (no skating). Impact 3, effort M, perf ~0 (math only); degrade: still poses already in `applyStill`. Data: `moving` + speed; scenery. Deps: `cityGraph` (heading tangent already provided).

## 4. Signature moment

Agent zoom on the Citadel steps at night: a needs-input Codex golem with banner raised and amber beam punching skyward, flanked by two hammer-swinging Foundry apprentices tethered by a light ribbon, while across the canal a jade-trimmed Claude archivist reads under orbiting thought-motes — provider, task and urgency readable in one frame.

## 5. Build sketch for the top 3 moves

**A. Heraldry kit (~180 LOC in `CourtyardCharacter.tsx`, +~40 test).** Technique: replace `lookFor(id)` with `lookFor(agent: Pick<CityAgent,'id'|'provider'|'model'>)`; `PROVIDER_KIT: Record<Provider,{hat,silhouette,trim,finial}>` = codex `{helm, ember #ff9b47}`, claude-code `{hood, jade #6fd8b8}`, opencode `{cap, sky #7fd0ff}`, manual `{cap, grey, emissive 0}`. Build trim from 2 shared `meshStandardMaterial` per provider (module-level cache, never cloned); dimmed variants pre-made by lerping once at startup (fixes today's per-render `new THREE.Color` in `432-439`). Model ticks: 0–3 small boxes on left shoulder from `model` hash or explicit suffix (`opus/sonnet/haiku/gpt-*` → 3/2/1/2). Keep deterministic coat fallback for Hydration. Files: `CourtyardCharacter.tsx`, new `heraldry.ts` (pure, unit-testable), `scenarioBridge` copy untouched. Pitfalls: don't clone materials per agent (breaks move 3); check deuteranopia — hue + shape both carry identity, never hue alone; `manual` must read unlit at all zooms.

**B. Zoom contract + LOD (~250 LOC in `Workers.tsx` + `CourtyardCharacter.tsx`).** Technique: `THREE.LOD` per worker with level 0 = current rig + finial (emissive cylinder r=0.09 h=1.1 above head + point-sprite glow), level 1 = 3-mesh proxy (capsule body `capsuleGeometry r=0.45 l=1.2`, head sphere, finial rod) sharing module materials, switch at 60 m. Shadows: `castShadow` only on LOD-0 meshes; LOD-1 `castShadow=false`. Finial pulse in the existing single `useFrame` (opacity/intensity by `phase`/`workState`); reduced-motion path sets static intensity via `applyStill` branch. Rings stay (1 draw) but far rings scale ×1.3 for legibility. Files: `Workers.tsx` (LOD + shadow flags + `workerTargets` unchanged), `CourtyardCharacter.tsx` (finial + proxy), `movement.ts` untouched. Pitfalls: `THREE.LOD` + R3F refs need `useMemo` geometries disposed on unmount; finial must not use `fog:false` additive like the beam (it should fog); arrival/departure fades (`lifecycle.ts:26-34`) must drive both LOD levels' materials — collect proxy mats in `collectMaterials`.

**C. State theatre (~200 LOC).** Technique: one `InstancedMesh` (additive `planeGeometry`, custom `onBeforeCompile` scroll or plain opacity pulse — no new dep) for motes/ripples/sigils, max 32 instances, updated in `Workers.tsx` frame loop from `runtime.agent.phase/toolKind/workState` (no React state). Thinking: 3 motes orbit r=0.9 at head height (`phase==='thinking'`); talking: ring scale 1→2.5 fade (`phase==='talking'`); tool: oversized arc quad at hand (`phase==='tool'` + `toolKind` → hammer/scroll/telescope palette). All frozen under `reducedMotion`/`paused` (reuse `pausedRef`/`reducedRef` guards). Needs-input keeps existing beam + raised banner pose. Files: `Workers.tsx` (instanced FX + loop), `CourtyardCharacter.tsx` (anchor empties only), `movement.ts` (no change — `gestureForWorker` stays the trigger). Pitfalls: FX must never play for `freshness!=='fresh'` (stale sits, historical idles); cap FX to fresh agents or overdraw spikes; additive blending + `depthWrite:false` to avoid plaza z-fights; keep FX inside `SLOT_RING_R` so districts layer isn't occluded.

## 6. Cut list

- Per-agent `Html` tags for all 24: keep ≤6 near/important, sprite or drop the rest (biggest DOM + layering cost).
- Per-mesh unique `meshStandardMaterial`s and per-render `new THREE.Color` lerps: share module materials + pre-made dimmed variants.
- `castShadow` on fingers/nose/beard/fur/torus micro-meshes: shadows on torso+head only (near LOD).
- Beard / fur collar / nose cone / shoulder-cloth micro-detail as identity: replaced by heraldry; keep one facial cue (eyes) at agent zoom.
- Hand-scale props as the distance channel: keep at agent zoom, never as the city-zoom signal (finial + sigil take over).
- Uncapped tethers + 6-leaving pileup: ribbon-per-family with cap 8; beyond-cap departures fade fast, no new geometry.
